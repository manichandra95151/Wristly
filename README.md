# Wristly

Wristly is an elegant and user-friendly watch management application that allows users to explore, wishlist, and purchase watches seamlessly. The application features a robust front-end built with React and utilizes Redux for state management, providing a smooth and responsive user experience.

## Features

- Browse a wide range of watches with images and details.
- Add watches to a personal wishlist for easy access.
- Manage cart items with options to add, remove, and update quantities.
- Intuitive UI with responsive design for mobile and desktop.

## Tech Stack

- **Front-End**: React, Redux Toolkit, Tailwind CSS
- **Icons**: Lucide React
- **State Management**: Redux
- **Routing**: React Router
- **Local Storage**: For persistent state management

## Installation

To set up the project locally, follow these steps:

1. **Clone the repository**:

   ```bash
   git clone https://github.com/manichandra95151/Wristly.git
   cd Wristly
   ```

2. **Install dependencies**:

   ```bash
   npm install
   ```

3. **Start the development server**:

   ```bash
   npm start
   ```

4. **Open your browser**:

   Navigate to `http://localhost:3000` to view the application.

## Usage

- **View Watches**: Navigate through the available watches, each displaying an image, brand, name, and price.
- **Wishlist**: Add watches to your wishlist using the heart icon. You can view your wishlist from the main menu.
- **Cart Management**: Add watches to your cart, adjust quantities, or remove items as needed.
- **Responsive Design**: The application is designed to work seamlessly on both mobile and desktop devices.

## State Management

This project uses Redux Toolkit for state management. The global state includes:

- **User Details**: Manages user authentication and details.
- **Wishlist**: Stores watches added to the wishlist.
- **Cart Items**: Manages watches added to the shopping cart, including their quantities.
